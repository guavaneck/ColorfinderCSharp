# ColorFinder 1.0.0

ColorFinder 1.0 delivers the complete first stable release of the lightweight color-focused file manager.

## Highlights

- Persistent, customizable file and folder color tags
- Automatic rules for extension, filename, path, regular expression, MIME type, age, and human-readable file size
- Grid and list browsing with previews, search, navigation history, and sidebar locations
- Create, rename, duplicate, copy, move, trash, open, and Open With actions
- Drag and drop within a window, between windows, into folders, and onto favorite locations
- Native Linux desktop integration assets
- Custom CSS skins loaded from the user configuration directory
- In-app interface palette controls for backgrounds, panels, controls, text, accents, and borders
- Terminal-style example skin and a complete skin-authoring guide

## Runtime notes

ColorFinder uses the operating system WebView rather than bundling Chromium. Linux requires GTK 3, WebKitGTK 4.1, and GStreamer base plugins. macOS uses WKWebView.
